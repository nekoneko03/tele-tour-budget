# Tele遠征費シミュレーター

Tele 2027ツアーの公演を選び、出発地域・交通手段・宿泊数から遠征費を比較するNext.jsアプリです。

## 必要環境

- Node.js 20.9.0以上

## ローカル実行

```bash
npm install
npm run dev
```

テストと本番ビルドは次のコマンドで実行します。

```bash
npm test
npm run build
```

## 主な機能

- 全16公演から参加候補を選択
- 11地域の代表拠点を起点に交通費と所要時間を概算
- 同一都市の連日公演を一つの遠征として集計
- 遠征ごとに交通手段、宿泊数、車の割り勘人数を調整
- 各遠征カードにチケット＋手数料、ドリンク、交通、宿泊、小計を表示
- 遠征ごとの交通手段、宿泊数、車の割り勘人数を含む共有URLを生成

公演情報は[Tele公式](https://tele.jp.net/live/2359/)を参照しています。

料金計算では、チケット＋サービス料を1公演あたり7,800円、ドリンク代を1公演あたり700円として固定しています。これらはシミュレーション用の設定値であり、公式発表の料金を示すものではありません。

交通費・所要時間・宿泊費は比較用の静的な概算です。実際の運賃、時刻表、空席、予約価格は各サービスで確認してください。
